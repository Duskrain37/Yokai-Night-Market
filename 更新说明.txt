妖怪夜市 v0.2（2026-10-30 更新）

运行方式：双击「妖怪夜市v0.2.exe」即可，单文件运行；首次启动会把内置资源解包到 LocalAppData\YaoguaiNightMarket\runtime。
环境：Windows 10/11 x64；需要系统 WebView2 Runtime（Win11 和大部分更新过的 Win10 自带；缺失时需安装 Microsoft Edge WebView2 Runtime）。

本版内容
- 备战镜头：夜市灯火 → 推向街尾 → 六种恶客列队 → 植物选择；点击或 Esc 跳过。
- 10 个出战槽位，选择自动记忆；悬停显示名称，右键植物/僵尸直接打开图鉴。
- 未带产能植物时提示“香火将断”；完全空栏时提示“空手开张”，2.4 秒或点击后强制返回选择，不能开战。
- 植物与僵尸按类型拆分动作：产能/射线/防御/辅助/范围/近战/灰烬；小/超小/重型/特殊僵尸。
- 僵尸战损形态、啃食动画、多发签筒间距 2×。
- 四档渲染分辨率：自适应 / 1280×720 / 1920×1080 / 2560×1600；自适应按窗口物理像素渲染，启动默认全屏，F11 可切换。
- 修复打包 exe 的字、植物与僵尸发糊：PerMonitorV2 DPI 感知 + 全屏 + 自适应物理像素渲染。
- 音乐整体重制为古风悬疑：古琴、竹笛、二胡、低音鼓、心跳、风声与钟磬；菜单 / 常态 / 白热化 / 最终四场递进。
- 石磨增加待机动画：缓慢碾磨起伏、石屑与地面尘环；受击有碎屑反馈。
- 山魈步态重做：大步幅重踏、落地压缩、尘浪与碎屑；血量改为 1800。
- 设置、存档、图鉴、升阶、作弊菜单与十关内容保持可用。

说明
- 音乐与音效为 Web Audio 实时合成，尚未做人耳精调混音。
- 单文件 exe 内嵌 www、WebView2 托管库与加载器；仍使用系统的 WebView2 Runtime。
- 存档与设置位置跟随 WebView2 用户目录（LocalAppData\YaoguaiNightMarket\WebView2）。
