妖怪夜市 v0.3.0 更新说明
发布：2026-11-01
从 v0.2.4（JS + Canvas）迁到 Godot 原生 2D。这是新版本线的第一版，内容按 v0.2.4 全量重做。

一、这一版是什么
  三天十五夜、18 种草木、12 种恶客、13 株的三路升阶、备战选卡、新手教程、自由训练场、
  草木志与恶客录三十篇、设置、对局存档——全部在新引擎里重做，不是把旧网页塞进壳里。
  Windows 版是单文件 exe，双击即玩，机器上不需要装 Godot。

二、相对 v0.2.4 的内容与体验变化
  1. 全部内容移植：十五夜 / 18 草木 / 12 恶客 / 完整三路升阶 / 训练场 / 图鉴 / 教学 / 设置 / 存档。
     数值照 old 版源码逐项搬，威胁 0.8—3.0、首波 17.5 秒、sqrt(威胁) 缩放都保持原样。
  2. 字体重做：正文用霞鹜文楷，标题用马善政毛笔字，都按游戏用字做了子集化。
  3. 界面重排：封面、新增的三天三列选关、备战「名册 / 卡组」分栏、局内左经济右工具、
     图鉴左名录右书页。旧版训练备战文字交叠与 HUD 裁切在结构上不会再出现。
  4. 增设「场内描格子」开关（设置 → 显示）：可以关掉棋盘每一格的线，只留外框。
  5. 草木与妖怪统一画风但逐个区分：每株/每种有各自的待机节奏、光色与出手特效；
     护具改为护罩光弧 + 型号色徽记 + 头顶双段血条，不再用一层手绘帽子盖住原画。
  6. 修掉 v0.2.4 已知的四个缺陷：
     · 教学香火落地后不再变成 10 秒后消失（旧版会卡死在第一步）；
     · 教学里说的升阶费用从数据表取值（旧版写死 75，实际是 90）；
     · 训练备战的右侧说明与卡组提示不再交叠；
     · 结算文案不再写「十夜还长」。
  7. 图鉴的「本事 / 底细」改为从数据表推导，改了数值图鉴会跟着改；
     旧版图鉴与代码是两份手抄稿，曾因此对不上。来历与引语原文照搬。

三、没有做到 / 已知差异
  1. 旧版「音乐风格：朴素 / 激昂」双轨没有移植。「朴素」是旧技术栈里的实时声学建模，
     本作保留 v0.2.4 的四条配乐（菜单 / 常态 / 白热化 / 最终），按波次自动切换。
  2. 存档格式是新的（JSON）。旧版 WebView2 里的存档不会被读取，也不会被改动。
  3. 只交付 Windows x64。macOS / Linux / Web / Android / iOS 都没有构建、没有实测，
     不做「可导出即已支持」的说法。
  4. 后期关卡的人手可通性没有结论：脚本策略能打通第一夜与第六夜，暗河只推进到第 8 波。
  5. 混音未做人耳精调；配乐沿用旧素材。

四、验证
  三套自动检查共 165 项全部通过，导出前必须通过才会打包：
    逻辑 88 项 / 自动对局 34 项 / 界面联调 43 项。
  另外在 Windows 11 上核对了独立 exe 冷启动、窗口标题、封面与对局渲染，
  以及 1280×720、1440×810、1600×900 三种窗口尺寸。
  检查结果与截图在工程的 qa/ 目录。

五、怎么玩
  双击 YokaiNightMarket.exe。首次进入先选「开始守夜」或「训练与教程」。
  左键选卡、点棋盘落子；点已种下的草木可升阶（三路里最多走两条，只有一条能到三级）；
  右键取消；空格暂停；F11 全屏。
  存档与设置写在 %APPDATA%\YokaiNightMarket\。

六、下载
  可执行文件与源码见本仓库的 Release 与 v0.3 分支；旧版 v0.2.4 的源码与成品仍在 v0.2.4 分支。
