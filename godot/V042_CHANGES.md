# 妖怪夜市 v0.4.2 更新公告

- **暗河开场与波次。** 第三周前两大波的敌群耐久总量降为原来的六成。第一大波前两拨只来低阶恶客。暗河的单位大小采用和夜市街一致的远近变化。局内换用朱砂旗进度条，每四大波翻页，最后不足四波时也均匀铺满。
- **首领。** 三位首领的生命提高 50%，小技能更频繁，伤害和干扰更强。首领在场时，常驻援军按常规波次耐久的 75% 出场。首领号令会另召出一整轮标准最终大波。
- **草木。** 新增跃起砸落的镇煞瓜和能切换近攻、仰射的龙首铳。汤圆仔改为 100 香火，烟花童改为 300。重做汤圆仔、香炉、醒狮和狐尾灯的指定进化，并缩短纸伞两个副收妖位的消化时间。龙首铳仰射每轮三发，铜弹飞行速度为汤圆的一半。
- **恶客。** 新增回灯鬼、红绳媒、双相傀、巡相师、持牌鬼、蒲舟客与梦铃婆。它们会复生、召唤、换相、抵挡射弹、驾舟或催眠。鬼新娘以图鉴喜轿里的素衣和红发带为准重画，轿内外一致。铁面与铁桶护具随脸部移动。
- **表现与操作。** 战斗动作提升到每组 32 帧，包含入水、复活、切换铳口和双口出手。开场与入战加入有真实进度的夜市加载页，画面交叠过渡。暂停页突出「重返游戏」。新手教程新增查看签筒图鉴的一步。
- **十五夜来客。** 每周第一夜熟悉地形，第二至第四夜各练一种应对，第五夜各路来客齐出并迎战首领。来客更换沿用原本每拨的数量、时刻与耐久预算。备战页的朱漆头像可以直接翻到首领录。蒲舟客依旧只来暗河，鬼新娘依旧随喜轿现身。
- **起土与进化。** 青铜莲瓣起土铲可拿在鼠标上，移除时草木随土屑抬起、收束。点另一株草木可立即切换扇面。新扇面以铜边漆面标出各路和费用，三阶进化时有短暂符印、金色余烬与独立钟音。
- **守夜救急。** 正式对局第一次打开作弊菜单会立即切到 0.1 倍，可在菜单里关回常规速度。用了慢放的对局按调整局记录。教程会说明三周的关卡安排、进化的两路限制和救急入口。
