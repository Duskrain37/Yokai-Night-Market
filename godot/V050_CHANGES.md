# 妖怪夜市 v0.5.0 更新公告

- **第四周 · 孤灯屿。** 五夜海岛夜市。摊面六行宽度依次为 5、7、9、9、7、5，边角是自然岩岸。每次开局有五处内格随机出现落石、碎木或破坛，恶客会翻越，障碍位置随存档保存。第五夜迎战潮灯夜叉。
- **第五周 · 冥判窟。** 五夜深入地下府衙。水面要先放夜莲，坑洞不能布阵。恶客会越坑、入水和登岸。玄冥判官在第五夜第四大波以限制形态出现，击退后继续守夜，第八大波再迎完整形态。
- **鬼市深处。** 改用地下棋盘，共二十大波。每四波清完迎战一位首领，保留阵容与香火，最后一战对上完整形态的玄冥判官。
- **关卡节奏。** 开局先练布阵，头两拨只来低阶恶客，前段压力降低，尾段更紧。新地图的水路、断崖和障碍已折进关卡难度。战斗进度仍每四大波翻页。
- **加载、备战与首领录。** 新加载插图画的是赴岛夜渡，书法字显示加载状态。备战的草木和来客名册分别滚动。首领录详列生命、出招时机、伤害、预警、持续时间和应对要点。
- **战斗表现。** 蒲舟击沉后有独立沉船过渡，船身下沉，蒲舟客接入游泳。两个新首领使用独立立绘及逐帧动作，鬼官的两种形态各有独立造型。
- **选关画卷。** 孤灯屿沿海岸折回山门，冥判窟跨过吊桥再折向判官门。每周五夜各落在一处地标。选关圆印中的数字重新居中。
- **配乐。** 孤灯屿与冥判窟各有先锋、白热化和决战三首新曲。白热化统一使用新篇。
- **发行包。** 打包后校验在役动画和立绘，移除过时备用内容、去重完全相同的资源数据。成品沿用 Windows x64 独立 exe，双击即可启动。
