中式夜市车道塔防：用香火请草木出摊，在灯火与水道之间守住夜市。五章二十五夜及「鬼市深处」，32 种草木、29 种恶客、5 位恶首。

## v0.6.0 更新

- 首页、选关、备战、图鉴、设置、战斗、暂停、加载和结算统一夜市材质、字体和层级。16:10 扩展画布并重新布局，画面铺满，单位与文字保持比例。
- 配乐统一为完整模式：菜单曲与五周十五首战曲；移除音乐风格选项及三首通用战曲。
- 图鉴先从左到右、再从上到下排列；路线展示对应三阶形态；完整显示血量与护具数值。难度说明重新排版。
- 龟甲罩重绘为向上开口的护甲碗，后沿、草木、前沿分层绘制，罩体与草木分别点击。战斗窗口外点击关闭并消费该次点击。
- 新增盗烬客与浮灯轿夫及 352 帧动作。盗烬客偷取并炼化香火，死亡返还未炼化部分；浮灯轿夫携带其他恶客飞行，护具破碎或靠近门神后共同落地。
- 镇霄炮基础炮弹改为灰烬伤害，可打陆上、水中，基础不能对空，绕过只挡射弹的护身牌。第三路为看破、八方碎霄、霄炮镇平安；看破优先于恶客闪避/免疫；8 枚弹片各 45 伤害；主动连续发射 7 枚 660 伤害重炮，间隔 0.25 秒，冷却 55 秒。
- 棋盘右缘出怪缓冲限制为半格，波次、召唤、后退和读档均遵守边界。
- 难度名为初月、常夜、沉夜、噩梦，数量和血量倍率为 0.8 / 1 / 1.1 / 1.2。
- 更新过程显示任务、百分比与下载分组。完成完整校验后保存记录，提示 5 秒倒计时并强制重启，也可立即重启。

本轮没有新增草木，也没有重复应用上版汤圆仔、铜铃的修改。完整分类和【前】→【后】对照见游戏内「夜市新讯」。

## 操作与存档

左键选卡、种植、查看或进化，右键取消。1—9、0、-、= 切换最多十二个卡槽，空格/P 暂停，Esc 返回，F11 全屏，方括号调整倍速；选卡与倍速可在设置中改键。难度在局外修改，备战选择噩梦因子。

点击龟甲罩查看护甲，点击草木查看进化。镇霄炮第三路三阶后，点击炮身旁朱红「镇」印发动主动技能，印记显示冷却。设置支持放大字号与减少动态。

玩家数据位于 `%APPDATA%\YokaiNightMarket\`，三个独立对局槽继续保留。请把 EXE 放在可写入目录，并为更新候选及缓存保留约 2 GB 空余空间。
