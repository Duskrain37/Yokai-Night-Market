# 妖怪夜市 v0.5.3 更新公告

## 新的守夜方式

- **夜市来到掌中**：新增安卓横屏版。轻点选择、种植和操作，长按取消；说明可以点开阅读，列表支持手指滑动。
- **开门先看新笺**：本版首次启动会打开更新公告。左边可切换到下载与反馈，查找正式下载地址或前往GitHub提建议。
- **各家灯火各有模样**：红灯笼、汤圆仔、钟馗像、铜铃、炭火盆等效果各有不同的纸火、热气、符印和声纹，更容易认清草木正在受到哪种照料。

## 守夜更顺手

- **沉舟后继续游**：蒲舟客的船被击沉后，改用完整的游泳动作，修正头顶出现脚部残影的问题。
- **狐火不会凭空熄灭**：追魂弹在途中失去目标，又无法另找来客时，会沿当时方向继续飞行，仍能打中途中碰到的恶客。
- **镇煞瓜及时出手**：种下时附近已有可攻击的恶客，会立刻开始蓄势扑击。

## 草木调整

- **逐云鸢**：消耗改为200香火，基础伤害改为40；散翼三阶的每发伤害分别为50、60、70。
- **烬翼蝉**：消耗改为275香火。
- **透骨针**：基础伤害提高到24，攻击间隔缩短至1.6秒。穿堂路线同时提高伤害至28、32、36；疾针路线的攻击间隔改为1.4、1.2、1秒。穿堂路线的进化费用相应提高。
- **香炉**：基础攻击间隔缩短至2.5秒，炉温路线依次缩短至2.15、1.8、1.45秒；香印的易伤改为10%、20%、30%。
- **炭火盆**：火色路线取消灼烧与掉落火星。新照明路线帮助周围九格内的生产型草木增加香火，满阶还会加快生产。火胎第二阶耐久提高到1500，满阶在被啃食时烧起一格火墙，脱离啃食便恢复生命。
- **铜铃**：摄心路线改为概率定身，满阶也能短暂停住大型恶客。清音路线可照顾整行，逐步学会唤醒沉睡草木，并在摇铃时恢复55生命。
- **汤圆仔**：优先攻击本行前方最近的恶客，基础攻击间隔改为2.3秒。暖心路线能照顾整行：没有恶客时，向友方投递温热汤圆，带来12%、18%、24%的伤害增幅；满阶温暖持续到本夜结束。
- **纸伞**：收妖时的风将普通恶客吹退0.9格，大型恶客减半。
- **五路巡灯**：基础即可齐发五道灯焰，未命中的灯焰会沿原路折返一次。照法提高单发伤害并可叠五层激励；旋法缩短攻击间隔，满阶在门神触发后短暂大幅增强；巡天逐步学会边界追魂，满阶同时放出直线灯焰和额外五颗追踪灯焰。
- **说明更统一**：草木说明统一使用“攻击间隔”。本次重做路线的香火费用也按新的效果重新调整。

本次没有新增草木或恶客。安卓横屏版独立发布，电脑版依然下载单文件 EXE 后直接启动。
