# v0.7.3 四周地图更新

- 河埠口：七垛不可种植的货物占住栈道。每大波轮换香船和货船，随机选一侧泊位，恶首所在的大波停航。船在泊位外最多候八秒；香船卸三百香火，货船通过绞盘搬走一垛货。香火仍受本局已启用的噩梦额度约束。
- 暗河：第二和第四行各有水路。每经过一个半大波预告六秒，然后切换两渠流向；水中普通恶客顺流快两成，逆流慢三成。首次换流时，两路来客几乎同时入场，方便比较。拖动浮席或点击另一头的空泊位；普通草木沿缆绳原株迁移，升阶和耐久不重置。
- 孤灯屿：海雾从最右三至四列卷来，预告后维持约二十五秒。雾区射弹、抛物线与追魂有五成落空率；必中仍可命中，靠近草木也会退出雾区。开场涨潮，第一大波不变，第二大波必退；之后抽签，连续两次同一潮位后必切。退潮时预报一侧的低栈，下一小批预定来客沿该路快五成，过了石栈恢复原速。
- 冥判窟：前四路的石闸可尝试在恶首先前拦住来客，动作维持五秒，共用三十秒冷却。第一、二行的桥不能种植，第三及第六大波会掉一段，合条件的第四及第七旗帜波衔木客有补桥木材。点断桥消耗一份木材而恢复通行。
- 新来客：挑担客、牵葫客、背罟鬼与衔木客分别在对应的周初遇，并进入后续适宜关卡的名单。各夜优先保留当夜要练的应对；备战名单计入带轿、召唤和地图新增来客。普通关最多十二种，恶首关最多十五种。
- 留白兰：仍优先治疗半血以下的草木；无伤重者时照顾最近尚未滋润的草木。落下的细叶与雨露跟随受益草木，状态牌同时列出减益和增益，数值按属性着色。

- 七组场景物件使用独立绘画，石闸的门板与石框分离。孤灯屿潮面采用三十二帧，静止的共用底图和变化的右岸帧合成完整画面。四个来客都有三十二帧移动、攻击和游泳动作图集。
- 中途旧档保留旧地形；新开的战斗使用新机制，保存潮池、泊位、浮席、木材和闸门进度。地图随机流与原出怪逻辑分离。鬼市深处沿用三十二大波与各段音乐。
