# 妖怪夜市 v0.5.5 更新公告

## 行囊与噩梦守夜

- **十二株同行**：常规守夜现在最多可带十二株草木。备战卡组与战斗牌栏重新排布，十二张牌各有自己的位置。新增第十至十二槽的默认按键：0、-、=，也可在设置更换。

- **行囊受限**：噩梦因子新增“行囊受限”：限带十株计一因子，限带八株计三因子。开战前请取下超出的牌；本局限制会随存档保留。

- **读清守夜规矩**：重新排版噩梦说明，较长的内容可上下滚动，不再从窗口边缘被截断。

## 守夜手感与效果修正

- **加成各有所用**：伤害与攻速加成仅对能攻击的草木生效，普通攻速不会催快香火生产。五窍灵枢可借用伤害加成，放弹节奏不受攻速影响；原弹与灵枢的加成分别乘算。

- **灰烬不留残影**：被灰烬伤害击退的恶客不再留下阻挡射弹的尸体，其他击退方式保留原有退场表现。

- **玩法整理**：移除“一夜重签”及其三张固定签题，守夜挑战继续保留在各夜的噩梦因子中。

- **烟花童三路新貌**：双响用双筒与双手烟花体现连发；满堂红换成宽圆花炮与牡丹壳；星河背起月架与星箭。三路满阶立绘和连续动画同步更新。

## 新草木与平衡调整

- **新增草木 · 岁灯榕**：每十秒产出五十香火，首次只需三秒。三十秒、六十秒时各成长一次，每次多产十五；修到任一路满阶后还可再成长两次。三路分别强化产能、榕籽连射、庇佑与明视，满阶“同心”还能照拂周围草木的伤害、攻速和生产。

- **新增草木 · 镇霄炮**：重炮瞄准恶客最密集处，一点五秒后落下，对一格内来客造成二百一十五伤害。三路分别强化连炮、灰烬破甲、击退返香与追魂余弹。本体与三路满阶形态均有独立立绘及连续动画。

- **草木调整 · 签筒**：“六发”为全队提供的额外竹签，叠加上限由三支提高至五支。

- **草木调整 · 五路巡灯**：门神被惊动后的临时强化提前至第二路一级获得；第二路三级新增击退激励：每次亲手击退提高百分之五攻速，持续五秒，最多五层，层数变化时刷新。

- **草木调整 · 透骨针**：第一路三阶伤害分别提高至三十、三十六、四十二。定影延长至零点六秒，大型恶客减半；解甲使本体多受百分之三十伤害、护具多受百分之六十伤害。

- **草木调整 · 汤圆仔**：暖心三阶增伤改为百分之十二、二十、三十；该路线费用下调，并按二十五香火的档位重新整理。

- **草木调整 · 铜铃**：清心新增同排攻击草木百分之十五攻速加成；清音路线费用下调，并按二十五香火的档位重新整理。
