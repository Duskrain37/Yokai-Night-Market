# 妖怪夜市 v0.7.2 · 兰香入深市

- 新增五味酿与留白兰。前者以射弹、抛弹、追魂和范围攻击组合触发酿印；后者利用空格或邻株，三路分别强化穿透、共生与雨露。两株都有初始与三路满阶造型。兰庭同息、天降甘霖分别有图形技能图标。
- 第六至八周各新增两位特色恶客。踏云役随升台疾行，提幕傀走完引路加速，循灯纸客受对应家门的灯光催步。蓑雾客、碎锣童、裂灯判客分别防灼、半血催步、一次挡重击。
- 鬼市深处新增独立舆图，战斗在第一周夜市街进行。32 大波分八段，威胁从 2.5 到 5.0。每段前二波是对应周的普通曲，后二波和恶首战仍播本周白热曲。现有进行中的存档保留其已保存的地图和段落规则。
- 穿透射弹、范围伤害分别结算外置护具和本体。阴舟被拆时，以扣完本体伤害后的剩余耐久计算落水客人。
- 三周各增加两项噩梦因子，界面显示香火、在场数、战损及接近上限提醒。云台预警显示方向和时间，戏班绸巷逐步展开，市灯仅灯身摇动，底座静止。

五味酿同一个目标只有一份酿印；扩散新增的计数留到下一种有效主类型命中后结算，反应自身不会再触发反应。留白布局稳定 0.55 秒后才计入。第三路的区域露水是全株单独的一条计时，每次只产生一层；如果没有半血以下的草木，暂存最多六层。

美术工作流：用内置 imagegen 绘制鬼市深处和透明角色关键姿势，裁入头像与锚点后，用 Godot 网格骨骼制作植物动作，以 DIS 光流烘焙 32 帧。输入图按「两株基础、六张满阶、六位恶客走路/攻击/受击、六位恶客另一侧步态与倒地」交给 `tools/prepare_v072_art.py`。技能徽章使用项目 SVG，雨露轨迹和墨叶使用战斗画布绘制。
