## 二、拿到图之后我怎么接

```powershell
# 透明化 + 裁边（绿幕/品红/白底都认）
python godot\tools\cut_sprites.py 原图.png godot\assets\sprites\mower-day1.png --height 420
python godot\tools\cut_sprites.py 石帽1.png godot\assets\sprites\armor-stonehat-1.png --height 320
```

- 门神：`board_view.gd` 会优先读 `mower-dayN.png`，没有才退回程序画的临时版。
- 护具：`unit_view.gd` 读 `armor-{straw|urn|mask|stonehat|paper|sedan}-{1,2,3}.png`，
  按血量 66% / 33% 换档，打碎时整块掉落。文件名对上就行，代码不用改。

## 三、如果暂时没有 Key

三个替代：
1. 用订阅通道（ChatGPT / Grok / Google 订阅）——在插件面板点「登录」，浏览器授权后免 Key；
2. 本地 ComfyUI —— 填 `http://127.0.0.1:8188` 并导入 API 格式工作流；
3. 让画这三张场景的画师顺手出这九张小图（我提供上面的提示词，他按 320×320 / 420 高透明出片即可）。
