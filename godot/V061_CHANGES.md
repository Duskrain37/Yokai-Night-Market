# 妖怪夜市 v0.6.1

本版补齐更新后的《草木改动与新增1.docx》，新增统一主动技能系统，重做钟馗像、签筒、炭火盆等进化，并优化镇霄炮临近落地锁定。

- 三种主动技能分别为神威护境、万签骤雨、霄炮镇平安，使用独立面谱、竹签雨、七重炮图形图标。技能位于模型中下部，冷却以圆形扇面显示。设置可开启进化面板、右键图标或两种方式；左键模型图标先打开面板，再点三阶图标施放。
- 唯一技能由最先解锁的在场钟馗像持有；持有者退场后按解锁顺序递补，冷却全场共享并写入存档。
- 不同来源减益乘算，同来源只取最高，较弱不延长较强效果；增益异源相加后再乘减益。图鉴新增属性计算与例子。
- 灵枢基础、2-1、2-2增伤为20%/35%/50%，2-3必定复制。醒狮第二路费用125/200/350，2-3间隔1.8秒；喝彩选择最高造价三株，满阶五株加自己、每层10%，使用独立鼓点特效。龙首铳耐久450。
- 岁灯榕第二路费用100/200/375，2-2伤害30+4×成长次数，2-3再获得2+成长次数枚连发。
- 钟馗像基础3×3、30%减伤，第一路45%/60%并在满阶扩大5×5，每株非灰烬草木独立60秒续命。第二路整行威慑与攻速20%/25%/30%，第二阶起影响大型；满阶主动全场庇护、驱散草木负面状态、沉默恶客，减速和攻速40%，持续8秒、冷却50秒。第三路增伤20%/30%/35%，满阶5×5；扩大范围与整行并存。
- 签筒1-3费用400，不再随机十二支，六发与全队额外五支保留。第三路概率缩短下次普通攻击间隔，满阶主动130发、0.02秒间隔、45秒冷却。
- 炭火盆最高阶数每阶增加500耐久；1-3溅射0.4格/40%；生产辅助20%并可扩大5×5。第三路为原本无穿透的射弹增加前向后续命中，伤害序列100/40、100/80、100/100/50%，保留原有穿透弹的能力。
- 镇霄炮总飞行1.5秒，落地前0.25秒锁定当前密集区，提示、弹道、爆炸和弹片中心一致。每枚主动重炮独立锁定。基础灰烬与地面/水中目标、盾牌绕过和第三路看破规则保留。
- 统一类型标签，修正备战筛选与图鉴文案。本轮无新增草木/恶客，汤圆仔与铜铃沿用此前版本。
- 旧对局按新上限迁移炭火盆、龙首铳耐久，保留已损失耐久；主动冷却、连发进度和每株续命冷却随存档保存。修复盗烬客定点特效更新读取速度字段报错。

旧版可通过游戏内更新，只下载与已有资源不同的内容。更新索引在最终 EXE 冻结、导出与整理后生成；完整校验后提示并强制重启。
