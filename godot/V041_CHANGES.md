# 妖怪夜市 v0.4.1 更新说明

- 暗河与河埠口障碍重绘。草木、三阶专属形态、恶客和首领接入连续动作帧；水路恶客下水时溅水，随后游动。高阶恶客留在陆路。
- 抬轿鬼分空轿与喜轿，各占一半。轿子碎裂后放出两只饿鬼；喜轿还会放出鬼新娘，她不会单独来袭，也不受灰烬类草木的伤害。护具破损有分档与碎片动作。
- 新增归风扇与烟花童，钟馗像转为庇护，透骨针重做穿透、疾针和易伤。狐尾灯、舞狮、纸伞、铜铃、炭火盆、五路巡灯重做指定进化，调整对应香火消耗。
- 坟头菇随时间长成，成熟有新形态与音效；爆竹炸开时有连续动作与爆炸效果。普通、追踪和抛射子弹的飞行速度均为原来的六成。
- 首领占据两行，命中其中任一行即可造成伤害，放过一至两个小技能后换行。被首领拆毁的草木不返香火。鬼市深处打退一位首领后立即进入下一段布阵期。
- 门神每路可救急一次。恶客在该路门神耗尽后走到防线尽头才算失守。若出战阵容没有生产香火的草木，备战会提醒。
- 局内调整即时生效。显示耐久时同时显示草木和恶客。波次进度、首领血条与文字面板改用圆角；选关移除「大岛航线」，封面的守夜记录改成通俗写法。
