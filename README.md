# 妖怪夜市 v0.2.2

中式夜市题材的 5×9 车道塔防。当前版本包含 16 种植物、12 种恶客（低/中/高三阶）、十关自由选关、10 个出战槽位、四档渲染分辨率、全屏启动，以及笙/箫/笛/二胡/古琴/琵琶与鼓磬的实时器乐配乐。

## 直接运行

- 双击 `release/妖怪夜市v0.2.2.exe`。这是单文件 exe，不需要旁边的 `www` 或 DLL。
- 首次启动会把内置资源解包到 `%LOCALAPPDATA%/YaoguaiNightMarket/runtime`。
- 开始游戏先进入「十夜」选关，第 1—10 关可自由选择。
- 默认全屏启动；F11 切换全屏。设置内可选自适应 / 1280×720 / 1920×1080 / 2560×1600 渲染分辨率。
- 环境：Windows 10/11 x64，需要系统 WebView2 Runtime（Win11 与大部分更新过的 Win10 自带；缺失时安装 Microsoft Edge WebView2 Runtime）。
- 存档在 `%LOCALAPPDATA%/YaoguaiNightMarket/WebView2`。

## 本版内容

- 16 种植物：红灯笼、签筒、石磨、爆竹、铜铃、香炉、纸伞、醒狮、坟头菇，以及狐尾灯、龟甲罩、汤圆仔、炭火盆、五路巡灯、透骨针、钟馗像。
- 狐尾灯自动追向全场绝对距离最近的恶客；龟甲罩只能罩在已有植物上，提供 1400 独立护甲；汤圆仔以抛物线固定攻击本行最右侧恶客；炭火盆增幅所有友方射弹；五路巡灯向五条路各发一道灯焰；透骨针穿透护具直接扣本体；钟馗像周期性显灵击退。
- 12 种恶客：饿鬼、长舌鬼、斗笠鬼、纸人、石帽鬼、瓮头鬼、跳幡鬼、哭丧鬼、山魈、抬轿鬼、纸扎匠、铁面判官。
- 僵尸生命分为本体血量与护具：攻击先扣护具，再扣本体；护具类型包括斗笠、石帽、陶瓮、纸壳、轿壳、铁面与纸甲。纸扎匠会周期性给附近低阶恶客分发纸甲。
- 普通恶客死亡动画 0.5 秒、大型恶客 1 秒；死亡瞬间停止啃食，但尸体继续阻挡射弹。
- 增伤、攻速、减速、易伤、灼烧、护甲支援全部取最高值，不叠加。
- 新手教程：收香火 → 种签筒 → 升阶 → 击退一只饿鬼；教程不写存档、不覆盖已有对局。
- 图鉴扩为 16 植物 / 12 恶客，备战植物卡 8×2、恶客卡 4×3，局内 HUD 支持 10 张出战卡。
- v0.2.1 存档可继续，旧 shell / maxShell 会转换为护具与本体血量。

## 源码结构

- `www/`：完整游戏前端、背景、单位贴图与 Web Audio 音频。
- `shell/`：单文件 WebView2 壳，含 `Program.cs`、`build.ps1` 与 WebView2 依赖。
- `开发模式.bat`：本地开发服务器。
- `CODEX_PROJECT_CONTEXT.md`：项目上下文与开发记录。

## 重新生成单文件 exe

```powershell
powershell -ExecutionPolicy Bypass -File shell/build.ps1 -Version 0.2.2 -Force
```

音乐与音效为 Web Audio 实时声学建模，并非真人录音采样；尚未做人耳精调混音。
