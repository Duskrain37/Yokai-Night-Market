# 妖怪夜市 v0.2.4

中式夜市题材的车道塔防。当前版本为 18 种草木、12 种恶客（低/中/高三阶）、三天十五夜共 15 关、教程与自定义训练场、四档渲染分辨率、全屏启动，音乐提供「朴素」（程序化合成）与「激昂」（AI 生成器乐）两套四轨配乐。

## 直接运行

- 双击 `release/妖怪夜市v0.2.4.exe`。这是单文件 exe，不需要旁边的 `www` 或 DLL。
- 首次启动会把内置资源解包到 `%LOCALAPPDATA%/YaoguaiNightMarket/runtime`。
- 环境：Windows 10/11 x64，需要系统 WebView2 Runtime（Win11 与大部分更新过的 Win10 自带；缺失时安装 Microsoft Edge WebView2 Runtime）。
- 存档与设置位于 `%LOCALAPPDATA%/YaoguaiNightMarket/WebView2`。
- 默认全屏启动，F11 切换全屏；设置内可选自适应 / 1280×720 / 1920×1080 / 2560×1600 渲染分辨率。

## 玩法结构

- 三天十五夜：第一天「夜市街」5 行，第二天「河埠口」6 行，第三天「暗河」5 行。
- 第二天每局在靠右 4 列随机放置 5 个障碍格（货摊/石墩/木箱），无法种植，位置随存档固定。
- 第三天加入物件格（栈桥/货台/香案）：草木放不上去，恶客踩到物件不啃食、直接前进；并加入水路（第 2、4 行的暗河与臭水沟）。
- 夜莲只能种在水面，作为浮台承载其他草木；缠魂藻是水面灰烬陷阱，恶客踩入水中即被拖沉，一次即散。
- 同一格有多层（夜莲+其上草木、宿主+龟甲罩）时，按鼠标命中的模型判定选谁，铲子可单独拆罩或单独铲莲。

## 单位

- 18 种草木：红灯笼、签筒、石磨、爆竹、铜铃、香炉、纸伞、醒狮、坟头菇、狐尾灯、龟甲罩、汤圆仔、炭火盆、五路巡灯、透骨针、钟馗像、夜莲、缠魂藻。
- 12 种恶客：饿鬼、长舌鬼、斗笠鬼、纸人、石帽鬼、瓮头鬼、跳幡鬼、哭丧鬼、山魈、抬轿鬼、纸扎匠、铁面判官。
- 恶客生命分为本体血量与护具：攻击先扣护具再扣本体；护具类型有斗笠、石帽、陶瓮、纸壳、轿壳、铁面与纸甲。纸扎匠周期性给附近低阶恶客分发纸甲。
- 普通恶客死亡动画 0.5 秒、大型 1 秒；死亡瞬间停止啃食，尸体继续阻挡射弹。
- 增伤、攻速、减速、易伤、灼烧、护甲支援一律取最高值，不叠加。

## 升阶与平衡

- 每座草木最多开两路、每路逐级、只有一路能到三级。
- 升阶费用按草木单独折算，使同一点灯火量下「一个满进化单位」的产出略低于若干白板单位（最强一路的收益约为费用增幅的 88%—91%）；满进化换来的是省格子。
- 关卡威胁倍率区间 0.8—3.0，出怪数量与血量各乘 sqrt(threat)；首波在 17.5 秒出场。

## 训练

- 主页「训练」分「教程」与「自定义训练场」。
- 教程：收香火 → 种签筒 → 升阶 → 击退一只饿鬼；强制 1 倍速，不写存档、不覆盖已有对局。
- 训练场：默认 1-1 地图、起手 1000 香火，全程不自动出怪、不判负、不写存档与战绩。两份作弊菜单——「杂项」加香火/秒杀/恢复门神/种植无冷却/消灭所有草木/切换地图（1↔2↔3 天，需重载）/切换携带草木/关闭；「召唤」按 12 种恶客选种、数量 1/3/5/10、分路（随机或指定行）手动出怪。

## 音频

- 音乐风格可选：「朴素」为 Web Audio 实时声学建模的笙/箫/笛/二胡/古琴/琵琶与鼓磬四轨；「激昂」为本地 ACE-Step 生成的四轨中式悬疑配乐（`www/assets/music/*.ogg`）。默认激昂，缺失文件时自动回退到程序化音乐。
- 设置内有音乐音量、音效音量两条 0%—100% 滑条与总开关，实时生效并持久化。
- 恶客受击音效按类型区分，尾音 0.072—0.115 秒；啃食按「石磨/龟甲罩＝碎石、其余＝湿咬」两套音效，0.3—0.42 秒一次，并同步咬合动作与碎屑粒子。
- 注意：「朴素」轨为实时声学建模而非真人录音采样；「激昂」轨为 AI 生成音频，尚未做人耳精调母带。

## 源码结构

- `www/`：完整游戏前端、背景、单位贴图、配乐与 Web Audio 音频。
- `shell/`：单文件 WebView2 壳，含 `Program.cs`、`build.ps1` 与 WebView2 依赖。
- `开发模式.bat`：本地开发服务器。
- `CODEX_PROJECT_CONTEXT.md`：项目上下文与开发记录。
- `更新说明.txt`：本版详细变更与验证记录。
