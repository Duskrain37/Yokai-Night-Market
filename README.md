# 妖怪夜市 v0.7.3

河埠口、暗河、孤灯屿与冥判窟各有新的地图玩法，新增挑担客、牵葫客、背罟鬼、衔木客。

一款中式怪谈题材的草木塔防游戏。八周四十夜，加一关鬼市深处；37 种草木、39 种普通恶客，以及各周恶首。PC 单机，中文界面。

## 下载后直接启动

在[最新正式发布](https://github.com/Duskrain37/Yokai-Night-Market/releases/latest)下载 **YokaiNightMarket-win64.exe**，双击直接玩，无需安装、解压或安装 Godot。不要下载 GitHub 自动生成的 Source code 压缩包来启动游戏。

已有电脑版可点封面“检查更新”，复用旧资源并只下载差异。更新器使用的 `YokaiNightMarket-update-map.json` 随 EXE 同步发布，玩家手动下载只需 EXE。若系统阻止启动，确认文件来自本仓库正式发布页。存档位于 `%APPDATA%/YokaiNightMarket/`，覆盖旧 EXE 保留进度。

## 本版新内容

- 河埠口：香船与货船轮流泊岸；清开泊位后可得三百香火，或腾出一块可种地。
- 暗河：两条水路的水流会交替变快、变慢；每条渠的浮席能载着草木换位。
- 孤灯屿：雾中恶客能躲开射弹，靠近草木会暴露。潮水改变两翼来路，退潮时岸灯会照出捷径。
- 冥判窟：可落下石闸阻敌；木桥坍塌后，击退衔木客取木补桥。
- 新增四位地形来客；每夜敌人安排与备战名单同步。局内可分辨草木的增益和减益，留白兰调整了雨露的目标优先顺序。

详见[更新说明](更新说明.md)。封面右上角“i”也能查看公告。

## 操作

左键选卡、种植、查看和进化；右键取消，或在已启用快捷释放时点击草木的技能图标。技能也可从进化面板施放。金蟾的形态切换按钮、更筹花的优先卡选择位于各自面板下方。迁根轿先点原草木再点新空格，右键取消不付费。

1—9、0、-、= 选择最多十二张卡；P/空格暂停，Esc 返回，F11 全屏。局内右上角可切换速度，支持 0.1 倍。设置提供字号、减少动态、战斗数字与改键；难度仅在局外更改。噩梦可自选因子，各颗星分别判断，不因丢失某颗星而吞掉其余奖励。
