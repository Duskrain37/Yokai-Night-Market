# 妖怪夜市 v0.6.1

[下载 Windows x64 独立 EXE](https://github.com/Duskrain37/Yokai-Night-Market/releases/latest/download/YokaiNightMarket-win64.exe)，下载后双击启动。已有 v0.5.6、v0.6.0 可在封面「检查更新」直接升级，复用已有资源，只下载差异。

[本版公告](https://github.com/Duskrain37/Yokai-Night-Market/releases/tag/v0.6.1) · [完整改动](更新说明.md)

中式夜市车道塔防，五章二十五夜与鬼市深处，32 种草木、29 种恶客、5 位恶首。本版保留 v0.6.0 的美术、分层龟甲罩、半格出怪缓冲、完整配乐及新增恶客，补齐最新草木改动文档。

- 三种主动技能：钟馗像「神威护境」、签筒「万签骤雨」、镇霄炮「霄炮镇平安」。各有独立图形图标、动画和特效；模型中下部显示就绪光环与圆形冷却扇面。
- 左键草木打开进化，再点已解锁三阶技能图标施放；也可右键模型技能图标。设置可选择任一种或同时开启。唯一技能归最先解锁的在场草木，退场递补时保留全场冷却。
- 重做钟馗像第二路、签筒第三路、炭火盆第三路；加强灵枢、醒狮、龙首铳与岁灯榕并调整指定费用。属性减益异源乘算、同源最高，图鉴提供计算说明与例子。
- 镇霄炮在落地前 0.25 秒锁定当前密集区，七枚重炮各自锁定，落点提示与实际伤害一致。
- 统一草木类型；兼容旧存档耐久及技能状态；修复盗烬客定点特效更新报错。本轮无新增草木，也不重复上版汤圆仔与铜铃改动。

左键选卡、种植、查看或进化，右键取消或施放已启用的技能快捷操作。1—9、0、-、= 选择最多十二卡槽，空格/P 暂停，Esc 返回，F11 全屏。支持放大字号、减少动态和改键。

更新器使用最终 EXE 的资源边界分块索引，只下载新增或改变的内容，支持断点续传、完整 SHA-256 校验、重启替换与失败回滚。v0.6.0 起更新完成会提示并在 5 秒后强制重启，也可立即重启。手动下载只需 EXE，JSON 索引供游戏自动读取。玩家数据位于 `%APPDATA%\YokaiNightMarket\`，三个独立对局槽继续保留。

源码阶段完成 24 套回归、80 项本版机制检查、14 项真实界面交互、三种分辨率原生画面与字体覆盖核验；100 场固定策略对局和 33 个恶首阵容样例完成。固定机器人胜局初月19、常夜15、沉夜14、噩梦12，仅代表该策略，机器人没有调用新主动技能，不是人工全流程通关认证。十五首获准战曲摘要不变。

本版沿用 v0.6.0 的提交历史，将补丁分支改为 v0.6.1；旧标签、附件及其他版本线保留，手机版未改动。Godot 4.7.2 打开 `godot/project.godot` 后 F5 运行。先完成源码验证，再冻结封包。引擎及字体授权见 MIT、OFL 与第三方声明。
