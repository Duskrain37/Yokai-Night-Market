# 妖怪夜市 v0.2.1

PvZ-like 5×9 车道塔防，中式夜市题材。当前版本包含 9 张卡、6 种恶客（低/中/高三阶）、十关自由选关、10 个出战槽位、四档渲染分辨率、全屏启动，以及笙/箫/笛/二胡/古琴/琵琶与鼓磬的实时器乐配乐。

## 直接运行
- 双击 `release/妖怪夜市v0.2.1.exe`。这是单文件 exe，不需要旁边的 `www` 或 DLL。
- 首次启动会把内置资源解包到 `%LOCALAPPDATA%/YaoguaiNightMarket/runtime`。
- 开始游戏先进入「十夜」选关，第 1—10 关可自由选择。
- 默认全屏启动；F11 切换全屏。设置内可选自适应 / 1280×720 / 1920×1080 / 2560×1600 渲染分辨率。
- 自适应档最高渲染 1920 宽，优先保证 60 帧；若需要 2560 原生清晰度，可选手动 2560×1600 固定档，但重负载局内可能低于 60 帧。
- 环境：Windows 10/11 x64，需要系统 WebView2 Runtime（Win11 与大部分更新过的 Win10 自带；缺失时安装 Microsoft Edge WebView2 Runtime）。
- 存档在 `%LOCALAPPDATA%/YaoguaiNightMarket/WebView2`。

## 本版内容
- 9 种植物：红灯笼、签筒、石磨、爆竹、坟头菇、铜铃、香炉、纸伞、醒狮。
- 坟头菇为灰烬陷阱：25 香火、14 秒长成，踩中喷发 1800 伤害并同归于尽，一次性不可升阶。
- 纸伞为收妖型前排：900 耐久，收起非大型恶客并咀嚼 6 秒；大型恶客改为每 2 秒受 40 伤害。
- 红灯笼三系增幅友军伤害（1/3 格/整行，+20/20/25%），铜铃二系增幅攻速（减速值的一半/等量，三级整行），均不叠加，只取最高值。
- 石磨可自愈或磨出碎石；碎石可附带 10% 易伤，三级对非大型击退 0.4 格、对大型双倍伤害。
- 铜铃减速 25%/1.5 秒；三系可对前方 4 格/整行造成 40 伤害，三级有 20% 概率定身 0.4 秒。
- 醒狮击退改为 0.2 格，1-3 增 50%，2-3 有 25% 眩晕。
- 性能缓存：静态场景、菜单底图与 HUD 条分层缓存；移除 `desynchronized` 合成以避免撕裂。

## 源码结构
- `www/`：完整游戏前端、2560×1440 背景、角色贴图与 Web Audio 音频。
- `shell/`：单文件 WebView2 壳，含 `Program.cs`、`build.ps1` 与 WebView2 依赖。
- `开发模式.bat`：本地开发服务器。
- `CODEX_PROJECT_CONTEXT.md`：项目上下文与开发记录。

## 重新生成单文件 exe
```powershell
powershell -ExecutionPolicy Bypass -File shell/build.ps1 -Version 0.2.1 -Force
```

音乐与音效为 Web Audio 实时声学建模，并非真人录音采样；尚未做人耳精调混音。
